# Food Order System

A simple web application for ordering food online, with a separate admin page to manage orders.

## Features
- Customers can browse the menu and place food orders
- Admin page to view and manage orders
- Data is stored locally in the browser (no external database needed)

## Built With
- HTML
- CSS
- JavaScript

## Project Structure
- `index.html` - customer ordering page
- `admin.html` - admin page
- `script.js` - front-end logic
- `backend.js` - order handling logic
- `localdb.js` - local data storage
- `style.css` - styling

## How to Run
1. Download or clone this repository
2. Open `index.html` in your browser to place orders
